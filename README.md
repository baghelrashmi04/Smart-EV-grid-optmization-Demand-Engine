# Smart-EV-grid-optmization-Demand-Engine
Developing an end-to-end machine learning and predictive analytics solution to optimize Electric Vehicle (EV) charging station efficiency, manage peak grid loads, and reduce utility demand charges. The project focuses on translating raw station metrics into actionable operational strategies to prevent grid spikes and minimize driver wait times.


Problem statement :
-EV charging network strains local grid , which congest localised charging , delay commercial network.
-Grid overload & congestions in peak hours creates long queue of drivers.
-EV companies sets EV points in prime locations giving high rate for infrastructure availablity, where they sits 70-80% empty whole day but hits 300% massive load in the evening rush time which causes high penality by utility distribution companies DISCOMS .


Solution:
-This time-series forecast project with a predictive dashboard predicts load spikes 24 hours in advance.
-Helps in dynamically optimise power distribution.
-Tells which nearby station will be overloaded so it redirects drivers to other free stations.
